🐝 Manual de Componentes ColmeIA

Este guia descreve os propósitos, aplicações práticas e estruturas HTML recomendadas para cada um dos 13 componentes de fluxograma do nosso ecossistema.

Root

Início do Fluxo

Root Start

O que faz: Representa o início de todo o processo de atendimento ou disparo do fluxo. Um fluxograma sempre deve ter exatamente uma raiz para que o leitor saiba por onde o bot começa.

<div class="node start">
                <strong>Root</strong>
                <p>Início do Fluxo</p>
                </div>
Fraseologia

Mensagem enviada no WhatsApp ou Chat para o usuário.

Fraseologia Msg

O que faz: Indica um balão de diálogo de conversa. Ele imita balões de gibi clássico e deve conter o texto exato que o usuário final lerá em seu canal de mensagem (WhatsApp, Webchat, Telegram, etc.).

<div class="node msg">
                <strong>Fraseologia</strong>
                <p>Mensagem do robô...</p>
                </div>
Decisão

O cliente quer prosseguir?

Decisão Decision

O que faz: Um losango que divide o fluxo em dois ou mais ramais (Forks). Use para direcionar caminhos como "Sim/Não" ou múltiplos comportamentos de resposta de botão.

<div class="node decision">
                <strong>Decisão</strong>
                <p>O cliente quer prosseguir?</p>
                </div>
Integração API POST /v1/salvar-lead

API Api

O que faz: Executa uma chamada HTTP para sistemas externos (back-ends, CRMs, etc.). Representada por uma caixa escura contrastante indicando operação sistêmica.

<div class="node api">
                <span class="k">Integração API</span>
                <span class="t">POST /v1/salvar-lead</span>
                </div>
Base Dados

Tabela: Lead_CIEE

Base de Dados Data

O que faz: Simula o cilindro de persistência física clássico de banco de dados. Use para sinalizar persistência em disco ou operações de INSERT/SELECT diretas no banco.

<div class="node data">
                <strong>Base Dados</strong>
                <p>Tabela: Lead_CIEE</p>
                </div>
Função

formataData(hoje)

Função Function

O que faz: Representada por um hexágono verde piscina. Ideal para expressar trechos com código, algoritmos lógicos e transformações estruturais rápidas de dados.

<div class="node function">
                <strong>Função</strong>
                <p>formataData(hoje)</p>
                </div>
Metadado

canal_origem: whatsapp

Metadado Metadado

O que faz: Salva chaves, valores ou variáveis na sessão do bot que serão transmitidos ao longo da árvore de atendimento em segundo plano.

<div class="node metadado">
                <strong>Metadado</strong>
                <p>canal_origem: whatsapp</p>
                </div>
Item de Menu

Opção [1] - Vagas Estágio

Item de Menu Menu

O que faz: Indica um item de menu numérico ou botão clicável. Útil para estruturar fluxos onde o usuário final faz escolhas guiadas por listas fixas.

<div class="node menu">
                <strong>Item de Menu</strong>
                <p>Opção [1] - Vagas Estágio</p>
                </div>
ColmeIA Forms

Formulário de Cadastro CIEE

ColmeIA Forms Forms

O que faz: Retângulo tracejado de tom amarelo-ouro. Usado para destacar quando o fluxo exige que o usuário preencha um formulário eletrônico de coleta estruturada de dados.

<div class="node forms">
                <strong>ColmeIA Forms</strong>
                <p>Formulário de Cadastro...</p>
                </div>
Validação

CPF válido?

Validação Validation

O que faz: Formato de losango em verde-claro. Perfeito para destacar checagens de integridade críticas no chatbot, como validações de CEP, CPF, e-mail e formatos de arquivos.

<div class="node validation">
                <strong>Validação</strong>
                <p>CPF válido?</p>
                </div>
Atendimento Humano

Fila: Comercial

Atendimento Humano Human

O que faz: Caixa quadrada vermelha com ícone vetorial de headset integrado no topo. Indica o ponto onde o bot encerra a automação de inteligência artificial e transiciona o chat para um atendente humano na plataforma.

<div class="node human">
                <strong>Atendimento Humano</strong>
                <p>Fila: Comercial</p>
                </div>
Decision Hub

Avalia Canal de Entrada

Decision Hub Hub

O que faz: Retângulo roxo de processamento estratégico. Usado em centrais lógicas para redirecionar usuários entre diferentes robôs de acordo com tags e horários.

<div class="node hub">
                <strong>Decision Hub</strong>
                <p>Avalia Canal de Entrada</p>
                </div>
Fim do Bot

Sucesso

Fim do Bot End

O que faz: Balão tipo pílula escuro que sinaliza o encerramento do script lógico de automação de mensagens.

<div class="node end">
                <strong>Fim do Bot</strong>
                <p>Sucesso</p>
                </div>
